# 编码与文档规范（经验固化）

> 这里只放可执行的硬规则。来源是 [LESSONS.md](../LESSONS.md) 中同一经验教训出现 **3 次** 后固化的条目，不放进度、设计细节或一次性提醒。

## 固化流程

1. 在 `LESSONS.md` 记录现象、教训与做法，并累计"出现次数"。
2. 同一教训第 3 次出现时，在本文件新增一条规则，写明规则、正例/反例与检查方式，并在 `LESSONS.md` 对应条目标注"已固化"。
3. 规则生效后，任务验收与代码评审按本文件检查。

## 规范

暂无固化条目（阈值：同一教训出现 3 次）。
